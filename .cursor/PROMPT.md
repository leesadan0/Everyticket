## 1. 사이트 확정본

다시 시키기 전에는 구성·카톡 아이디·메뉴를 바꾸지 않는다.

- 모달: 아이디 복사 · 카카오톡 앱 열기 · 친구 추가(ID). PC·모바일 같음
- 메뉴: 서비스 · 이용안내 · 접수현황 · 예매 인증 · 고객 후기 · Why Us · FAQ · 문의양식 · 상담 신청
- **컴퓨터는 글자 메뉴.** 노란 햄버거는 **휴대폰만** (620px 이하). 미리보기 창이 좁아도 글자 메뉴가 보이게 둔다
- 본문 순서: 서비스 → 이용안내 → 접수현황 → 예매 인증 → 고객 후기 → Why Us → FAQ → 문의양식 → 카톡 상담
- 메뉴·상담 버튼을 누르면 해당 섹션 제목(`sec-head`)이 헤더 바로 아래에 맞춰 멈춘다. 문의양식도 같다
- 지금 문의하기 · 상담 신청 · 히어로 카카오톡 무료 상담은 카톡 창이 아니라 `#inquiry`로 간다
- 문의양식 태그: `문의양식` (INQUIRY 쓰지 않음)
- 문의 양식: 양도 / 댈티. 복사 첫 줄 `문의 : 양도` 또는 `문의 : 댈티`
- 문의 CTA: 상담은 무료이니 편하게 문의 부탁드립니다. 상담시간·평균응답·결제방식 줄 없음
- 접수현황: 한 페이지 9개. 검색. 탭 전체/접수중/오픈예정. 데스크톱 3열. 모바일만 2열
- 예매 인증: 한 페이지 6개. 같은 공연·같은 공연일 1장. 공연일 늦은 순. 데이터 `assets/data/proofs.json`
- 고객 후기: 한 페이지 9개. 검색. 탭 전체/아옮/댈티. 아옮은 위·공연일순, 댈티는 아래·티켓팅순
- 댈티 후기: 선예매 전·선착순만. 업체가 겁주지 않음. 고객이 무서워·바빠서 맡긴 말투
- 카드 초록 pill = 티켓팅, 노랑 pill = 공연일. `open`도 선예매 기준

## 3. 에브리티켓 첨삭 · 삭제 (사이트)

날짜와 한국시간을 어기지 않는다. 오픈공지 목록을 채팅에 보여 주거나 허락을 구하지 않는다.

- **20:00** `EveryTicket-2000-Update` — 4사 API로 접수현황·고객 후기를 맞춘 뒤 `shows.json`을 main에 올린다
- **21:00** `EveryTicket-2100-Remove` — 마지막 공연일 **전날 21:00**이 된 공연을 바로 뺀다. 다시 묻지 않는다
- 스크립트 `세팅\everyticket-daily.ps1`. Cursor 채팅 대기·클라우드 오토메이션 쓰지 않는다
- 예: 마지막 공연 9월 20일 → 9월 19일 21:00부터 목록에서 내린다. 20일 당일에는 이미 없다
- 페이지를 열 때도 그 시각이 지났으면 바로 숨긴다

### 접수현황에 넣는 기준

- 4사: 인터파크 · 티켓링크 · 멜론 · 예스24. **API만.** 브라우저 HTML 덤프 금지
- 장르: 콘서트 · 팬미팅 · 음악 페스티벌. 뮤지컬 · 연극 · 전시 · 토크쇼 · 토크콘서트 제외
- 인기: `isHot` 이거나 조회 **500+**
- 필수: 포스터, 공연일. 없으면 접수현황에 넣지 않는다 (오픈공지는 댈티 후기에만)
- 개수 제한 없음. 조건 맞는 건 다 넣는다
- **티켓팅 날짜 = 선예매일.** 팬클럽/멤버십 선예매가 있으면 그걸 쓰고, 없을 때만 일반예매일
- 접수중 / 오픈예정은 날짜만이 아니라 **선예매 시각**. 시각이 지나야 접수중
- 공연날짜 변경 공지: 공연일만 고친다. 취소 공지: 뺀다. 공지 없이 추측하지 않는다

## 5. 4사 API (브라우저 HTML 금지)

- 인터파크 상품: `GET https://api-ticketfront.interpark.com/v1/goods/{코드}/summary`  Referer `https://tickets.interpark.com/`
- 인터파크 오픈: `GET https://tickets.interpark.com/api/open-notice/notice-list?sorting=OPEN_ASC&goodsGenre=CONCERT&goodsRegion=ALL&pageSize=50&offset=0`
- 티켓링크 오픈: `GET https://www.ticketlink.co.kr/help/getNoticeList?page=1&noticeCategoryCode=TICKET_OPEN&title=&sortCode=OPEN_DATE`  (등록순 `REGISTE_DATE`도 본다)
- 멜론 오픈: `GET https://ticket.melon.com/csoon/ajax/listTicketOpen.htm?orderType=2&pageIndex=1&schGcode=GENRE_CON&schText=&schDt=`  `X-Requested-With: XMLHttpRequest`
- 예스24 오픈: `POST https://ticket.yes24.com/New/Notice/Ajax/axList.aspx`  `page=1&size=40&genre=&province=&order=2&searchType=All&searchText=`
- 예스24 상세: `POST .../axRead.aspx`  `bId=` (id 아님). 공지 `https://m.ticket.yes24.com/Notice/{id}`

좌석도에 없는 구역은 추측하지 않는다.

## 6. 양도 / 아옮 / 댈티

- **아옮 = 양도.** 양도글(양식1)을 쓴다. 댈티와 섞지 않는다
- 링크만 주고 종류를 안 밝히면 먼저 묻는다
- 해시태그 전문 유지. 맨 뒤 항상 `#[아티스트명] #[공연명키워드]`. 양도는 공연장 알면 `#[공연장명]` 추가
- **영어만 있는 제목일 때만** 아랫줄에 한글 제목. 제목에 한글이 1글자라도 있으면 한글 줄 쓰지 않는다
- 댈티 파일명: `댈티 [콘서트명].txt`. 오픈일은 `세팅\_open-dates.json`. 파일명 앞에 오픈일 붙이지 말 것
- 제목에 `대리티켓팅` 넣지 않는다. 👇 쓰지 않는다
- 아옮 문의: `문의는 프로필링크 참고!` (`오픈톡문의` 금지)

### 인기콘서트 목록 · 당일 메모

NOL · 예스24 · 티켓링크 · 멜론만. 일주일 이내, 콘서트/팬미팅, 조회 500+, 오픈 시각까지 사이트에서 확인.

- **오늘 18:00 이후 오픈** → 당일 18:00에 아옮 작성. 선예매가 안 지났어도 기다리지 않는다
- **댈티:** 오픈공지·오픈예정에 뜨면 바로. 일주일 기다리지 않음. 조회 500+ 유지. **HOT**만 조회·기간 묻지 말고 즉시

트위터 자동업로드 창은 **매크로프로그램**이라고 부른다. TicketerK라고 쓰지 않는다.

## 7. 트위터 일정 (매일)

하루 **00:00 · 11:00 · 18:00 · 21:00**만. 30분마다 돌리지 않는다.

- **00:00** SMemo `당일 공연`만. 그날 인기콘서트 당일오픈. 다른 s메모는 건드리지 않음
- **11:00** 윈도우: 댈티 저장. 아옮: 이미 지난 오픈 + 그날 18:00 이전 오픈. 좌석 있으면 중나
- **18:00** 윈도우: 새 댈티(그날 18:00 이후 오픈 포함). 아옮: 그날 18:00 이후 오픈 + 아직 양도 없는 것
- **21:00** 댈티·양도·중나 삭제 (마지막 공연일 전날만). 오픈 당일에 지우지 않는다
- 아옮은 배치도에서 구역·열 확인한 것만. 좌석 없으면 양도·중나 안 만듦
- Convert-DeltaToYangdo 호출 금지. 오픈일에 댈티를 양도로 바꾸거나 지우지 말 것
- 대기 터미널 1개. 끊기면 바로 다시. 다시 켤 때 `일정 자동 다시`

## 8. 양도 좌석 (매번)

배치도·가격 확인 → 있는 구역·열만. 형식: `✅[층] [전석 또는 등급] [구역] [열, 열]`

- 가격 같으면 `전석`. 등급 다르면 등급 (가짜 R석 금지)
- 한 구역 한 줄. 열은 보통 2개. 1~5열만. 배치도에 있는 열만
- 구역은 배치도에 있는 것만. 알파벳 순. `2층 정면` 금지
- 스탠딩은 입장번호 필수. `2x번대`~`12x번대`. `x번대`로 씀

## 9. 중고나라

아옮 최신화할 때만 `세팅\중나`. 댈티 최신화에는 넣지 않는다.

- 양식 `세팅\templates\junggonara-yangdo.txt`. 제목 `💎`, 날짜 `👉`, 좌석 `⭕️`. 가격·직거래 없음
- 파일: `[끝나는월.일] 중나 [콘서트명] 글.txt` 바로 다음 `… 사진.jpg`
- 포스터는 그 예매상품 공식 이미지만. 다른 공연 사진 복사 금지
- 트위터 해시태그·프로필링크·댈티 본문은 중나에 넣지 않음
