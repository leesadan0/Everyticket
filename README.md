# 에브리티켓 (EveryTicket)

티켓 양도 · 대리예매 · 선예매 전문 대행 서비스 소개 사이트입니다.
빌드 도구 없이 동작하는 정적 사이트(HTML/CSS/JS)로, `index.html`만 열면 바로 확인할 수 있습니다.

## 폴더 구조

```
everyticket/
├─ index.html              # 전체 페이지 (원페이지 구성)
├─ assets/
│  ├─ css/style.css        # 디자인 시스템 + 전체 스타일
│  ├─ js/main.js           # 메뉴, 필터, 카운트업, 스크롤 등장 효과
│  └─ img/hero-banner.png  # 메인 배너 이미지
└─ README.md
```

## 페이지 구성

| 섹션 | 내용 |
|---|---|
| 히어로 | 브랜드 배너 + 핵심 카피 + 카카오톡 상담 CTA |
| 지표 | 누적 성공 건수 / 성공률 / 상담 시간 / 운영 경력 (스크롤 시 카운트업) |
| 서비스 | 티켓팅 · 예약 · 입찰 · 신청 대행 4종 카드 |
| 이용 절차 | 상담 → 예약금 예치 → 대행 착수 → 결과 안내 및 후불결제 |
| 접수현황 | 전체 / 접수중 / 대행성공 탭 필터 |
| 성공내역 | 공연별 성공 건수 카드 (더 보기 토글) |
| 이용 이유 | 실패 시 0원, 전담 인력, 실시간 안내, 개인정보 보호 |
| FAQ | 아코디언 6문항 |
| 문의 | 카카오톡 채널 CTA + 안내 카드 |

## 로컬에서 보기

```powershell
# 방법 1 — 파일을 그대로 열기
start index.html

# 방법 2 — 로컬 서버 (권장)
python -m http.server 5173
# http://localhost:5173 접속
```

## 배포 전 바꿔야 할 항목

1. **카카오톡 채널 주소** — `index.html`에서 `data-placeholder="kakao"` 가 붙은 링크의 `href`를 실제 채널 URL로 교체
2. **채널 아이디** — `.qr__name` 의 `@에브리티켓` 문구
3. **사업자 정보** — 푸터의 상호명 / 사업자등록번호 / 대표번호
4. **접수현황 · 성공내역** — `#showList`, `#successGrid` 안의 카드 항목
5. **QR 이미지** — `.qr__box` 자리에 실제 카카오톡 QR 이미지 삽입 시 `<img>`로 교체

## 색상 팔레트

배너 이미지에서 추출한 값이며 `assets/css/style.css` 상단 `:root`에서 한 번에 수정할 수 있습니다.

| 변수 | 값 | 용도 |
|---|---|---|
| `--yellow` | `#FFCE3D` | 메인 포인트, CTA 버튼 |
| `--yellow-deep` | `#F2A93B` | 버튼 그림자, 강조 텍스트 |
| `--green` / `--green-deep` | `#7CC24A` / `#4F9B36` | 보조 브랜드 컬러, 배경 밴드 |
| `--sky` | `#8FD5E8` | 히어로 하늘 배경 |
| `--cream` | `#FFFBEF` | 페이지 기본 배경 |
| `--ink` | `#3E3320` | 본문 텍스트 |

## 브라우저 지원

최신 Chrome / Edge / Safari / Firefox. `IntersectionObserver` 미지원 환경에서는 애니메이션 없이 정적으로 노출됩니다.
`prefers-reduced-motion` 설정 시 모든 애니메이션이 자동 비활성화됩니다.
